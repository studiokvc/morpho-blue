# 12. Limites du parcours

Ce parcours est une lecture documentaire du cœur Morpho Blue.
Les coffres, les modèles de taux concrets et les implémentations d’oracle restent hors périmètre.
Un mauvais prix d’oracle ou un token au comportement inhabituel peut compromettre un marché.
La liquidation dépend aussi de liquidateurs capables de financer leur intervention.
Aucune installation, compilation, exécution de tests ou transaction blockchain n’a été effectuée.
La [suite de tests du dépôt](../../test) fournit les scénarios à lire pour prolonger l’étude.
